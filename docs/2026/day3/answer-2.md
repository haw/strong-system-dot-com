# Day 3 障害2の答え：名前を引けない

[Day 3 のハンズオン](./)の 4-2 の答えです。

## 原因

Parameter Store の `/day3-2026/{あなたの名前}/db/host` が、本当のエンドポイントと1か所だけ違っています。`-db-` が `-bd-` になっていて、存在しない名前なので引けません。

## 根拠

- アプリケーションのログの `host=` と、RDS のコンソールのエンドポイントが一致しない。
- `getent hosts "$DB_HOST"`（本当のエンドポイント）は IP アドレスが出るのに、ログの `host=` の名前では何も出ない。

## 直し方

1. **Systems Manager** の「パラメータストア」で `/day3-2026/{あなたの名前}/db/host` を開き、「編集」を選ぶ。
2. 「値」を、RDS のコンソールからコピーしたエンドポイントに置き換え、「変更を保存」を選ぶ。
3. 4-0 のコマンドで、アプリケーションを起動し直す。

## 現場では、こうして起きる

接続先を設定し直す作業で、エンドポイントをコピーせずに手で打ち、打ち間違えた。長い名前を手で写すと起きやすい誤りです。

## 直ったときの見え方

`ENOTFOUND` は消えます。代わりに、しばらく待たされてから `ETIMEDOUT` が出ます。障害3（4-3）に進みます。
