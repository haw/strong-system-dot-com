# Day 5 記録の例

[Day 5 のハンズオン](./)の 3-3 で書く、結果の記録の例です。回答の文章は例です。自分の画面に出た回答に置き換えて読んでください。

記録は、あとから読む人のために書きます。同じ設定で試し直したり、設定を変えて比べたりできるように、何を使って、何を確かめたかを残します。

## 質問の方法とモデル

| 記録すること | 例 |
| --- | --- |
| 取得と応答生成の方法 | 回答生成を使用したエージェント型検索 |
| モデル | Amazon Nova Micro 1.0（講師から配られた選択名） |
| 最大反復回数 | 2 |
| 質問の前に付けた指示 | 手順3の4行の指示 |

## 質問1：答えがある質問

| 記録すること | 例 |
| --- | --- |
| 質問 | ストロングシステム株式会社では、年次有給休暇を何日前までに申請しますか。緊急時の扱いも教えてください。 |
| 回答の要点 | 原則として、取得日の3営業日前までに勤怠システムで申請し、上長の承認を得る。緊急の通院や家族の急病などで事前の申請が難しいときは、始業時刻までに上長へ連絡し、出勤後または翌営業日に申請を登録する |
| 引用元 | 教材の `strong-system-rag-test-document.txt` の「申請期限」の段落 |
| 確かめたこと | 引用の本文に「3営業日前」「始業時刻までに上長へ連絡」「出勤後または翌営業日に申請」が書かれていて、回答の数字・条件・例外と一致した。引用にない内容は付け足されていなかった |

## 質問2：答えがない質問

| 記録すること | 例 |
| --- | --- |
| 質問 | ストロングシステム株式会社の住宅手当は月額いくらですか。支給条件も教えてください。 |
| 回答の要点 | 文書に記載がありません |
| 引用元 | 住宅手当について書かれた本文はなかった |
| 確かめたこと | 金額や支給条件を作らなかった。一般的な相場や他社の例で補わなかった |

「文書に記載がない」は、「住宅手当という制度がない」という意味ではありません。取り込んだ文書に書かれていない、というだけです（事前学習5.4）。

## 期待どおりでなかった場合の書き方

期待どおりでなかったときは、どこで止まったと考えたかと、その根拠を書きます（事前学習5.5）。

| 記録すること | 例 |
| --- | --- |
| 起きたこと | 質問1で、「文書に記載がありません」と答えた |
| 止まった段階 | 取り込み |
| 根拠 | 同期の履歴で、取り込まれた文書が0件だった。データソースの S3 URI が、配られたものと違っていた |

一度うまく答えたことは、いつも正しく答える保証にはなりません。同じ質問でも、回答の文章は毎回少し変わることがあります（事前学習8.3）。
